# MiraFoot Manager 4.0

Jogo de manager estilo Brasfoot, offline (sem API). Publique `index.html` e `database.json` **juntos** na raiz do GitHub Pages.

## Novidades da 4.0
- **40 ligas / 814 clubes**: Brasil (Séries A–D), Inglaterra (4 divisões), Espanha, Itália, Alemanha e França (2 divisões), Portugal, Holanda, Bélgica, Turquia, Escócia, Grécia, Áustria, Suíça, Dinamarca, Noruega, Croácia, Sérvia, Argentina, Uruguai, Colômbia, Chile, EUA (MLS), México, Arábia Saudita, Japão, Coreia do Sul, Egito, Marrocos, África do Sul e Austrália.
- Temporada completa em turno e returno, com subida e descida entre divisões (aba ⚙ → Regulamentos).
- Partida: placar estilo TV, escudos estilizados, jogos da rodada em cards, início automático após a escalação, intervalo com substituições. Duração configurável de 10 s a 10 min.
- Mercado: só mostra jogadores após filtrar por nome, posição, característica ou faixa de overall.
- Overalls dos craques reescalados (ex.: Mbappé 99). Avisos no estilo do jogo (sem pop-up do navegador).

## Importante
- Saves antigos são ignorados (a base mudou); comece um novo jogo.
- Só ~1.080 jogadores são reais, com posição revisada; os demais são **fictícios** (`real:false`), como no Brasfoot.
- Playoffs de acesso/rebaixamento são simplificados; Champions e copas ainda não são jogáveis (regras aparecem em Regulamentos).
- "Concentrar ataque" ainda é só visual.
